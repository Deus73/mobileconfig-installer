# Floreal MobileConfig Installer

Eenvoudige webpagina om `.mobileconfig`-profielen via Safari op iOS te installeren (uploaden, via URL of XML plakken).

Gebaseerd op [mobileconfiginstaller.js.org](https://mobileconfiginstaller.js.org/).

## GitHub Pages
Publiceer deze repo via **Settings → Pages** (bijv. branch `main`, map `/ (root)`) om de installer via een HTTPS-URL in Safari te openen.
